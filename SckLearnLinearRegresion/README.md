# SAT Score Linear Regression

## Overview

This project demonstrates how to build a simple linear regression model using **scikit-learn** to predict a student's Grade Point Average (GPA) based on their SAT score.

The project walks through the complete machine learning workflow, including data exploration, visualization, model training, evaluation, and prediction using a single independent variable.

---

## Business Problem

Educational institutions often seek to understand whether standardized test scores can help predict future academic performance.

This project explores the relationship between SAT scores and GPA using simple linear regression. While SAT scores alone cannot fully explain academic success, they provide a practical example of predictive analytics and supervised machine learning.

---

## Dataset

The dataset contains two variables:

| Variable | Description |
|----------|-------------|
| SAT | Student SAT score (independent variable) |
| GPA | Student Grade Point Average (dependent variable) |

## Installation

1. Clone this repository:

```bash
git clone https://github.com/yourusername/SAT-Score-Linear-Regression.git
```

2. Navigate to the project directory:

```bash
cd SAT-Score-Linear-Regression
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open **SAT Score Linear Regression.ipynb** and run all cells from top to bottom.
