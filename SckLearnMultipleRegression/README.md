# Student GPA Multiple Linear Regression

## Overview

This project demonstrates how to build a multiple linear regression model using scikit-learn to predict a student's Grade Point Average (GPA) using multiple independent variables.

The notebook walks through the complete machine learning workflow, including data exploration, model training, evaluation, visualization, and prediction.

---

## Business Problem

Predictive models often rely on more than one factor to estimate an outcome.

This project demonstrates how multiple regression can improve predictions by incorporating more than one independent variable when estimating student GPA.

Although this example uses a simple educational dataset, the same workflow applies to many real-world business problems such as forecasting sales, predicting home prices, or estimating customer lifetime value.

---

## Dataset

The dataset contains the following variables:

| Variable | Description |
|----------|-------------|
| SAT | Student SAT Score |
| Rand 1,2,3 | Additional independent variable included for regression modeling |
| GPA | Student Grade Point Average (Target Variable) |

## Getting Started

### Option 1: Download the Repository

1. Click **Code** → **Download ZIP**
2. Extract the project folder

### Option 2: Clone the Repository

```bash
git clone https://github.com/yourusername/Student-GPA-Multiple-Regression.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Notebook

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open **Multiple Linear Regression.ipynb** and run all cells.
